# Acknowledgments

Thanks to **Franco Venturi (fventuri)** and **ON8ST** for the research,
documentation and tooling published in
[fventuri/g7250-base](https://github.com/fventuri/g7250-base).
Comparing findings from another approach has helped our G7250 investigation,
particularly the head protocol, hardware interfaces and firmware architecture.

OpenG7250 uses its own firmware-analysis workflow. The reference project's
development methodology does not define ours. Agreement between analyses of
the same image is useful corroboration, not a substitute for hardware tests.
