# HIS 70 — Main↔Control link

**Evidence:** g7250-base peripherals docs (**rests on disassembly**). Emulator
observation (re/emu D1): in a two-machine run the Main and Control USART2 ports,
connected to each other, carry traffic.

- **Main USART2** is wired to **Control USART2** over the CTRL cable.
